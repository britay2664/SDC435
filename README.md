## Assignment 1.8 Redis Set Manager

redisSetManager.py is an interactive Python application that uses
redis-py to create, retrieve, update, and delete Redis sets. Users
can add or remove set members and clear the application database.
The application uses local Redis database 3 and displays the
system date and time.

Run using a Python environment with the redis package installed:

python redisSetManager.py

The Redis server must be running before starting the application
